Quick Tips
💡
Start with the Hero Section Always fill in your event name, date, and a short description in the Hero Banner first — this is what residents see first.
🏷️
Publish as a Template Use "Publish as Template" in the Event Builder to save your layout. Templates are reusable — great for recurring events like monthly vaccinations.
📅
Link Templates to Calendar When creating a calendar event, select a template. The public event page will automatically go live during the event's date range.
👁️
Preview Before You Publish Use "Preview ↗" in the Event Builder to see exactly how the page will look before linking it to a calendar event.
